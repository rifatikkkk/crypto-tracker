# Предварительный контракт API

## Общие правила

- Все маршруты `/coins` требуют `Authorization: Bearer <API_KEY>`.
- `symbol` — символ монеты, например `BTC`.
- Время возвращается в UTC в формате ISO 8601.
- Цены запрашиваются и сохраняются в `USD`.
- Ошибки возвращаются в формате `{ "error": "описание" }`.

## Маршруты

| Метод  | Путь                 | Назначение               |
| ------ | -------------------- | ------------------------ |
| GET    | `/health`            | Проверка запуска         |
| POST   | `/coins`             | Добавить пару            |
| GET    | `/coins`             | Получить список пар      |
| GET    | `/coins/:id`         | Получить пару            |
| PATCH  | `/coins/:id`         | Изменить пару            |
| DELETE | `/coins/:id`         | Удалить пару             |
| GET    | `/coins/:id/price`   | Получить актуальную цену |
| GET    | `/coins/:id/history` | Получить историю цен     |
