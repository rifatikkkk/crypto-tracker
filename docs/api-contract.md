# Контракт API

## Общие правила

- Все маршруты `/coins` требуют `Authorization: Bearer <API_KEY>`.
- `/health` доступен без API Key.
- `cmcId` — числовой идентификатор монеты в CoinMarketCap.
- `symbol` — символ монеты, например `BTC`.
- Время возвращается в UTC в формате ISO 8601.
- Цены запрашиваются и сохраняются в `USD`.
- Ошибки возвращаются в формате `{ "error": "описание" }`.

## Реализованные маршруты

| Метод  | Путь                 | Назначение                                |
| ------ | -------------------- | ----------------------------------------- |
| GET    | `/health`            | Проверка запуска                          |
| POST   | `/coins`             | Добавить отслеживаемую монету             |
| GET    | `/coins`             | Получить список монет                     |
| GET    | `/coins/:id`         | Получить монету по внутреннему ID         |
| PATCH  | `/coins/:id`         | Изменить монету                           |
| DELETE | `/coins/:id`         | Удалить монету                            |
| GET    | `/coins/:id/price`   | Получить актуальную цену из CoinMarketCap |
| GET    | `/coins/:id/history` | Получить сохраненную историю цен          |

Техническое описание интерфейса API представлен в [спецификации OpenAPI 3.0](openapi.json). Файл `docs/openapi.json` можно открыть в Swagger Editor.

### POST `/coins`

Тело запроса:

```json
{
  "cmcId": 1,
  "symbol": "BTC",
  "name": "Bitcoin"
}
```

Все три поля обязательны:

- `cmcId` должен быть положительным целым числом
- `symbol` — от 2 до 15 символов в верхнем регистре: буквы латинского алфавита и цифры
- `name` — непустая строка до 100 символов.

Ответы:

- `201` — монета создана; возвращается объект монеты.
- `400` — некорректное тело запроса.
- `401` — отсутствует или неверен API Key.
- `409` — монета с таким `cmcId` уже отслеживается.

### GET `/coins`

Ответы:

- `200` — массив отслеживаемых монет; если записей нет, возвращается `[]`.
- `401` — отсутствует или неверен API Key.

Пример объекта в массиве:

```json
{
  "id": 1,
  "cmcId": 1,
  "symbol": "BTC",
  "name": "Bitcoin",
  "createdAt": "2026-10-08T12:00:00.000Z"
}
```

### GET `/coins/:id`

`:id` — положительное целое число, внутренний ID записи сервиса.

Ответы:

- `200` — объект монеты.
- `400` — некорректный ID.
- `401` — отсутствует или неверен API Key.
- `404` — монета не найдена.

### PATCH `/coins/:id`

Маршрут требует **все три поля** — `cmcId`, `symbol` и `name`. Формат тела такой же, как у `POST /coins`.

Ответы:

- `200` — обновлённый объект монеты.
- `400` — некорректный ID или тело запроса.
- `401` — отсутствует или неверен API Key.
- `404` — монета не найдена.
- `409` — указанный `cmcId` уже принадлежит другой монете.

### DELETE `/coins/:id`

Ответы:

- `204` — монета удалена; тело ответа пустое.
- `400` — некорректный ID.
- `401` — отсутствует или неверен API Key.
- `404` — монета не найдена.

### GET `/coins/:id/price`

`:id` — положительное целое число, внутренний ID монеты в этом сервисе.

Пример ответа:

```json
{
  "coinId": 1,
  "cmcId": 1,
  "symbol": "BTC",
  "currency": "USD",
  "price": "65000.25",
  "updatedAt": "2026-10-08T12:00:00.000Z"
}
```

Ответы:

- `200` — цена получена.
- `400` — некорректный ID или неподдерживаемые параметры запроса.
- `401` — отсутствует или неверен ключ доступа к нашему сервису.
- `404` — монета не отслеживается.
- `500` — ошибка конфигурации сервиса.
- `502` — ошибка запроса к CoinMarketCap или некорректный ответ.
- `503` — превышен лимит запросов CoinMarketCap.
- `504` — истёк таймаут запроса к CoinMarketCap.

### GET `/coins/:id/history`

`:id` — положительное целое число, внутренний ID монеты в этом сервисе.

Необязательный параметр `limit` задаёт максимальное число записей. Допустимы целые числа от `1` до `100`; по умолчанию используется `100`. Другие параметры запроса не поддерживаются.

Пример ответа:

```json
[
  {
    "id": 2,
    "coinId": 1,
    "price": "82981.82",
    "currency": "USD",
    "recordedAt": "2026-10-09T11:00:00.000Z"
  },
  {
    "id": 1,
    "coinId": 1,
    "price": "82975.10",
    "currency": "USD",
    "recordedAt": "2026-10-09T10:00:00.000Z"
  }
]
```

Записи отсортированы от новых к старым. `recordedAt` — время обновления котировки, полученное от CoinMarketCap. Если у монеты ещё нет сохранённых цен, возвращается `[]`.

Ответы:

- `200` — массив записей истории, в том числе пустой.
- `400` — некорректный ID, `limit` или неподдерживаемый параметр запроса.
- `401` — отсутствует или неверен API Key.
- `404` — монета не найдена.

## Автоматическое обновление

После запуска сервиса фоновая задача запрашивает актуальные цены отслеживаемых монет и сохраняет их в SQLite. Следующий цикл начинается после завершения предыдущего; циклы не выполняются одновременно.

Интервал задаётся переменной `SYNC_INTERVAL_MS`. Значение по умолчанию — `60000` миллисекунд; значения меньше `60000` не допускаются.

Повторный снимок одной монеты в той же валюте и с тем же временем обновления не добавляется в историю. Ошибка при обновлении одной монеты записывается в журнал сервиса и не останавливает обновление остальных.

При `SIGINT` или `SIGTERM` сервис прекращает запуск новых циклов, дожидается текущей работы, закрывает HTTP-сервер и соединение с SQLite.

Маршрут `GET /coins/:id/price` возвращает актуальную цену из CoinMarketCap, но сам по себе не сохраняет её в историю.
