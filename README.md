# Crypto Tracker

Backend-сервис для отслеживания криптовалют и хранения истории цен из CoinMarketCap API.
Сервис предоставляет REST API для управления списком монет, получения актуальной цены и чтения истории цен из SQLite.
Фоновая задача регулярно обновляет и сохраняет цены отслеживаемых монет.

## Возможности

- Аутентификация через `Authorization: Bearer <API_KEY>`.
- Создание, просмотр, изменение и удаление отслеживаемых монет.
- Получение актуальной цены монеты из CoinMarketCap в USD.
- Автоматическое сохранение истории цен в SQLite.
- Получение истории цен с ограничением числа записей.
- Корректная остановка фоновой задачи при `SIGINT` и `SIGTERM`.
- Документация API в формате OpenAPI 3.0.

## Стек

- Node.js 24+
- Express.js
- TypeScript
- SQLite через встроенный модуль `node:sqlite`, без ORM
- axios
- Jest и Supertest
- OpenAPI 3.0
- Docker и Docker Compose — для альтернативного запуска

Node.js 24+ требуется для работы с `node:sqlite` без стороннего SQLite-драйвера.

## Установка и запуск

```bash
npm install
npm run build
npm start
```

По умолчанию сервер запускается на `http://localhost:3000`. Проверка запуска: `GET /health`.

Для разработки:

```bash
npm run dev
```

## Настройка

Файл `.env.example` содержит образец переменных окружения. На его основе внутри проекта создайте файл `.env` и заполните переменные окружения:

```dotenv
PORT=3000
DATABASE_PATH=./data/prices.sqlite
API_KEY=your-service-api-key
CMC_API_KEY=your-coinmarketcap-api-key
CMC_TIMEOUT_MS=5000
SYNC_INTERVAL_MS=60000
```

`API_KEY` защищает маршруты этого сервиса. `CMC_API_KEY` используется сервером для запросов к CoinMarketCap.

При запуске Node.js загружает значения из локального файла .env. Переменные, уже заданные в окружении системы, имеют приоритет над значениями файла.

Файл базы данных создаётся локально и не добавляется в репозиторий.

## Тесты

Запустите все тесты:

```bash
npm test
```

Команда сначала собирает TypeScript, затем запускает Jest. Тесты используют Supertest и проверяют маршруты API, ошибки, валидацию и фоновое обновление.

## Документация API

- [OpenAPI 3.0](docs/openapi.json) — описание всех реализованных маршрутов.
  Файл можно открыть в Swagger Editor.
- [Контракт API](docs/api-contract.md) — описание запросов, ответов и правил сервиса.

Все маршруты `/coins` требуют заголовок
`Authorization: Bearer <API_KEY>`.
Маршрут `/health` доступен без ключа.

## Фоновое обновление

Сервис обновляет цены при запуске. Следующий цикл начинается после завершения предыдущего и паузы `SYNC_INTERVAL_MS`. Значение по умолчанию и минимум — `60000` миллисекунд.

Фоновая задача сохраняет историю цен в SQLite. Повторные снимки
с одинаковым временем обновления не дублируются. Маршрут
`GET /coins/:id/price` получает актуальную цену, но не сохраняет её
в историю.

## Запуск через Docker Compose

Создайте локальный `.env` на основе `.env.example` и заполните `API_KEY` и `CMC_API_KEY`.
Затем запустите:

```bash
docker compose up --build -d
```

API будет доступен по адресу `http://localhost:3000`.
Данные SQLite хранятся в именованном томе `prices_data`.

Остановить сервис:

```bash
docker compose down
```
